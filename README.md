# iwamad-sis3-tasks

A mobile task manager built with React Native (Expo) and TypeScript.
Create, view and delete tasks; swipe to delete, long-press to mark done; animated rows.

Pages: https://btanat.github.io/iwamad-sis3-tasks/
Deep link: https://btanat.github.io/iwamad-sis3-tasks/tasks/1

## Run locally
```
npx expo start
```

## Publish to GitHub Pages
```
npm run export:web
git add .
git commit -m "..."
git push
```
Then: Settings → Pages → Deploy from a branch → main → /docs.
